# SOEN-343-Project
**CityCircuit** is a centralized platform that integrates shared mobility services, parking systems, and public transportation data to provide real-time trip planning, availability monitoring, analytics, and administrative tools for smart city mobility management.

## Project Overview

This is a **full-stack Next.js application** using the App Router.  
It includes a frontend UI, backend API routes, and a database layer powered by Prisma.

---

## Structure

### .next/
Build output generated by Next.js (not source code).

### node_modules/
Installed dependencies (Next.js, React, Prisma).

### src/
Main source code.

#### src/app/
Frontend routes:
- `/` → Home page
- `/planner` → Trip planning interface
- `/admin` → Admin dashboard

#### src/app/api/
Backend API routes:
- `/api/trips/plan` → Generates trip plans
- `/api/admin/metrics` → Returns admin analytics
- `/api/mock/checkout` → Mock payment endpoint

### src/lib/
Shared utilities and provider integrations (e.g., routing, payments).

### prisma/
Database schema and migrations.
- Uses Prisma ORM
- Stores and manages application data (e.g., trips, metrics)

---

## Architecture Summary

User (Browser)
→ Planner UI (`/planner`)
→ API Route (`/api/trips/plan`)
→ Providers + Prisma (data/services)
→ JSON response
→ UI renders results

Single codebase handling:
- UI
- Server logic
- Database access
